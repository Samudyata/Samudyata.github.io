Software engineering agents

SWE-Bench Agent

Repository

Built an evidence-routed multi-agent system for SWE-bench and SWE-bench-C that generates patches for real GitHub issues using planner, localizer, diagnostician, patcher, and validator roles.

Core idea

Instead of retrying the full pipeline after failure, the system classifies evidence from patch, compile, and test errors, then routes it back to the agent that can act on it.

Infrastructure

Built tree-sitter code dependency graphs for C repositories, with keyword-weighted traversal and confidence-scored include, call, type-use, and test edges.
